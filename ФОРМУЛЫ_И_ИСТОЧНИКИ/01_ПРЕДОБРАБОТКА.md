# Формулы предобработки

## Гамма-коррекция

Обобщённая форма для нормированного значения яркости:

`y = x^γ`, где `x, y ∈ [0, 1]`.

В литературе и программных фильтрах также используется соглашение `y = x^(1/γ)`. Эти варианты дают противоположное направление изменения яркости при одном и том же γ.

**Статус: `НЕ ПОЛУЧЕНО` из работы Лосева.** До получения L04 нельзя выбирать соглашение только по названию операции. Необходимо выписать из статьи:

- точную формулу;
- диапазон γ;
- используемый канал или цветовое пространство;
- нормализацию и квантование;
- обработку значений 0 и 1;
- место преобразования относительно смены pixel format.

## Контрастное растяжение

Типовая линейная форма:

`y = a + (x − x_min) · (b − a) / (x_max − x_min)`.

Здесь `[x_min, x_max]` — исходный диапазон, `[a, b]` — целевой. Для 8-битного полного диапазона часто используют `[0, 255]`, однако это нельзя автоматически переносить на limited-range YUV.

**Статус: `ВНЕ РАБОТ ЛОСЕВА / ТРЕБУЕТ СОГЛАСОВАНИЯ`.** Нужно определить:

- границы по всему видео или отдельно по кадру;
- минимум/максимум либо перцентили;
- обработку случая `x_max = x_min`;
- работу только с яркостью или со всеми компонентами;
- clipping, округление и разрядность.

## Требуемые тесты реализации

- `γ = 1` не меняет значения;
- границы диапазона остаются допустимыми;
- монотонность преобразования сохраняется;
- константный кадр не вызывает деления на ноль;
- несколько контрольных значений совпадают с ручным расчётом;
- результат одинаков при повторном запуске.
