# Постановка задачи

## Цель

Экспериментально оценить устойчивость объективных метрик PSNR, SSIM и VMAF к гамма-коррекции и контрастному растяжению видеопотока перед кодированием.

## Объект и предмет исследования

- Объект: видеопоследовательности 1280×720, 1920×1080 и 3840×2160 (4K), представляющие статичные, динамичные и текстурно-насыщенные сцены.
- Предмет: изменение показаний PSNR, SSIM и VMAF после предобработки и сжатия кодеками H.264, H.265 и AV1.

## Основные задачи

1. Подобрать 10–15 легально доступных видеопоследовательностей и составить manifest с их характеристиками и лицензиями.
2. Реализовать гамма-коррекцию и контрастное растяжение по формулам из проверенных научных источников.
3. Реализовать воспроизводимое кодирование H.264, H.265 и AV1 через FFmpeg.
4. Рассчитать PSNR, SSIM и VMAF для базовой и экспериментальной схем.
5. Сопоставить результаты по метрике, кодеку, параметрам сжатия, виду предобработки, типу контента и разрешению.
6. Определить условия, при которых предобработка искусственно повышает объективную оценку качества.

## Экспериментальные схемы

Базовая схема:

`оригинал → кодирование → декодирование → расчёт метрик`

Экспериментальная схема:

`оригинал → предобработка → кодирование → декодирование → расчёт метрик`

Основной показатель:

`ΔM = M(экспериментальная схема) − M(базовая схема)`,

где `M` — PSNR, SSIM или VMAF. Точное определение референсного видео для каждой метрики необходимо зафиксировать до запуска.

## Ограничения

- Все исходные данные должны иметь подтверждённую лицензию.
- Версии FFmpeg, libvmaf и энкодеров фиксируются.
- Режимы разных кодеков сопоставляются по обоснованному критерию; одинаковый CRF не считается автоматически эквивалентным качеством.
- Полный эксперимент запускается только после успешного пилота для каждого кодека и отдельной проверки 4K.

## Критерии завершения

- эксперимент воспроизводится из конфигурации;
- каждый запуск имеет статус и журнал;
- получены машиночитаемые таблицы и графики;
- выводы прослеживаются до исходных данных и параметров;
- явно описаны ограничения исследования.
